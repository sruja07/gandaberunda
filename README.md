# Gandaberundha

A full-stack application structure with dedicated **Frontend** and **Backend** directories.

## Project Structure

```
gandaberundha/
├── frontend/    # Frontend application (Vite + React)
├── backend/     # Backend application (Node.js + Express)
└── README.md    # Documentation
```

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running

#### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

#### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
